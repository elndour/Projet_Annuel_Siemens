  PROCÉDURE COMPLÈTE DE TEST - GUIDE DÉTAILLÉ
  Environnement de Test Local avec 2 PCs
  Projet Siemens - Data Collection & Analysis
═══════════════════════════════════════════════════════════════════════════════

📌 OBJECTIF DE CE GUIDE
-----------------------
Ce guide vous accompagne pas à pas pour transformer vos 2 ordinateurs personnels
en environnement de test complet pour le système de collecte de données Siemens.

À la fin de ce guide, vous serez capable de :
✅ Collecter des fichiers via SSH/SFTP depuis localhost et un PC distant
✅ Extraire des données depuis une base SQLite de test
✅ Tester le packaging et le cryptage des données
✅ Débugger et développer sans serveurs de production


═══════════════════════════════════════════════════════════════════════════════
  PHASE 1 : PRÉPARATION DE L'ENVIRONNEMENT (30 minutes)
═══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 1.1 : INSTALLATION DE SSH SUR LE PC 1 (Votre ordinateur principal)   │
└─────────────────────────────────────────────────────────────────────────────┘

1️⃣ Ouvrir PowerShell en tant qu'Administrateur
   ────────────────────────────────────────────
   🔹 Windows 10/11 : 
      - Clic droit sur le menu Démarrer
      - Sélectionner "Terminal (Admin)" ou "Windows PowerShell (Admin)"
      
   🔹 Vous devriez voir une fenêtre avec :
      PS C:\Windows\system32>

2️⃣ Vérifier si SSH est déjà installé
   ──────────────────────────────────
   Commande :
   ┌────────────────────────────────────────────────────────────────┐
   │ Get-WindowsCapability -Online | Where-Object Name -like 'OpenSSH*' │
   └────────────────────────────────────────────────────────────────┘

   Résultat attendu :
   ┌────────────────────────────────────────────────────────────────┐
   │ Name  : OpenSSH.Client~~~~0.0.1.0                              │
   │ State : Installed                                              │
   │                                                                │
   │ Name  : OpenSSH.Server~~~~0.0.1.0                              │
   │ State : NotPresent  ← Si vous voyez "NotPresent", continuez   │
   └────────────────────────────────────────────────────────────────┘

3️⃣ Installer OpenSSH Server
   ─────────────────────────
   Commande :
   ┌────────────────────────────────────────────────────────────────┐
   │ Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0  │
   └────────────────────────────────────────────────────────────────┘

   ⏱️ Temps d'installation : 1-2 minutes
   
   Résultat attendu :
   ┌────────────────────────────────────────────────────────────────┐
   │ Path          :                                                │
   │ Online        : True                                           │
   │ RestartNeeded : False                                          │
   └────────────────────────────────────────────────────────────────┘

4️⃣ Démarrer le service SSH
   ────────────────────────
   Commande 1 : Démarrer SSH
   ┌────────────────────────────────────────────────────────────────┐
   │ Start-Service sshd                                             │
   └────────────────────────────────────────────────────────────────┘

   Commande 2 : Configurer le démarrage automatique
   ┌────────────────────────────────────────────────────────────────┐
   │ Set-Service -Name sshd -StartupType 'Automatic'                │
   └────────────────────────────────────────────────────────────────┘

   Commande 3 : Vérifier que SSH tourne
   ┌────────────────────────────────────────────────────────────────┐
   │ Get-Service sshd                                               │
   └────────────────────────────────────────────────────────────────┘

   Résultat attendu :
   ┌────────────────────────────────────────────────────────────────┐
   │ Status   Name               DisplayName                        │
   │ ------   ----               -----------                        │
   │ Running  sshd               OpenSSH SSH Server                 │
   └────────────────────────────────────────────────────────────────┘

5️⃣ Configurer le pare-feu Windows
   ────────────────────────────────
   Commande :
   ┌────────────────────────────────────────────────────────────────┐
   │ New-NetFirewallRule -Name sshd -DisplayName 'OpenSSH Server'  │
   │   -Enabled True -Direction Inbound -Protocol TCP              │
   │   -Action Allow -LocalPort 22                                 │
   └────────────────────────────────────────────────────────────────┘

   Résultat attendu :
   ┌────────────────────────────────────────────────────────────────┐
   │ Name                  : sshd                                   │
   │ DisplayName           : OpenSSH Server                         │
   │ Description           :                                        │
   │ DisplayGroup          :                                        │
   │ Group                 :                                        │
   │ Enabled               : True                                   │
   │ Profile               : Any                                    │
   │ Platform              : {}                                     │
   │ Direction             : Inbound                                │
   │ Action                : Allow                                  │
   │ EdgeTraversalPolicy   : Block                                  │
   └────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 1.2 : CRÉER UN UTILISATEUR DE TEST SUR LE PC 1                       │
└─────────────────────────────────────────────────────────────────────────────┘

1️⃣ Créer l'utilisateur "testuser"
   ──────────────────────────────
   Commande :
   ┌────────────────────────────────────────────────────────────────┐
   │ net user testuser test123 /add                                │
   └────────────────────────────────────────────────────────────────┘

   Résultat attendu :
   ┌────────────────────────────────────────────────────────────────┐
   │ La commande s'est terminée correctement.                       │
   └────────────────────────────────────────────────────────────────┘

   ⚠️ SI VOUS VOYEZ UNE ERREUR DE POLITIQUE DE MOT DE PASSE :
   
   Erreur possible :
   ┌────────────────────────────────────────────────────────────────┐
   │ Le mot de passe ne répond pas aux exigences de stratégie      │
   └────────────────────────────────────────────────────────────────┘

   Solution : Utilisez un mot de passe plus complexe
   ┌────────────────────────────────────────────────────────────────┐
   │ net user testuser Test@2025! /add                             │
   └────────────────────────────────────────────────────────────────┘

2️⃣ (OPTIONNEL) Ajouter aux administrateurs
   ────────────────────────────────────────
   ⚠️ ATTENTION : Ceci donne des privilèges élevés
   
   Commande :
   ┌────────────────────────────────────────────────────────────────┐
   │ net localgroup Administrators testuser /add                   │
   └────────────────────────────────────────────────────────────────┘

3️⃣ Vérifier que l'utilisateur existe
   ──────────────────────────────────
   Commande :
   ┌────────────────────────────────────────────────────────────────┐
   │ net user testuser                                             │
   └────────────────────────────────────────────────────────────────┘

   Résultat attendu :
   ┌────────────────────────────────────────────────────────────────┐
   │ Nom d'utilisateur           testuser                           │
   │ Nom complet                                                    │
   │ Commentaire                                                    │
   │ ...                                                            │
   │ Le compte est actif          Oui                               │
   └────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 1.3 : TESTER LA CONNEXION SSH LOCALE                                 │
└─────────────────────────────────────────────────────────────────────────────┘

1️⃣ Tester la connexion SSH vers localhost
   ───────────────────────────────────────
   Commande :
   ┌────────────────────────────────────────────────────────────────┐
   │ ssh testuser@localhost                                         │
   └────────────────────────────────────────────────────────────────┘

   🔹 Première connexion - Vous verrez un message de sécurité :
   ┌────────────────────────────────────────────────────────────────┐
   │ The authenticity of host 'localhost (::1)' can't be established│
   │ ECDSA key fingerprint is SHA256:xxxxxxxxxxxxxxxxxxxx.         │
   │ Are you sure you want to continue connecting (yes/no/[fingerprint])? │
   └────────────────────────────────────────────────────────────────┘

   👉 Tapez : yes
   👉 Appuyez sur Entrée

   🔹 Entrer le mot de passe :
   ┌────────────────────────────────────────────────────────────────┐
   │ testuser@localhost's password:                                │
   └────────────────────────────────────────────────────────────────┘

   👉 Tapez : test123 (ou le mot de passe que vous avez choisi)
   👉 Appuyez sur Entrée
   
   ⚠️ Le mot de passe ne s'affiche pas quand vous tapez (c'est normal)

2️⃣ Résultat attendu si connexion réussie
   ──────────────────────────────────────
   ┌────────────────────────────────────────────────────────────────┐
   │ Microsoft Windows [Version 10.0.19045.xxxx]                   │
   │ (c) Microsoft Corporation. All rights reserved.               │
   │                                                                │
   │ testuser@VOTRE-PC C:\Users\testuser>                          │
   └────────────────────────────────────────────────────────────────┘

   ✅ SUCCÈS ! Vous êtes connecté en SSH !

3️⃣ Quitter la session SSH
   ───────────────────────
   Commande :
   ┌────────────────────────────────────────────────────────────────┐
   │ exit                                                           │
   └────────────────────────────────────────────────────────────────┘

   Vous retournez à votre session PowerShell normale


┌─────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 1.4 : (OPTIONNEL) CONFIGURATION DU PC 2                              │
└─────────────────────────────────────────────────────────────────────────────┘

⚠️ PRÉREQUIS : Les 2 PCs doivent être sur le MÊME RÉSEAU LOCAL
   (même WiFi ou connectés au même routeur/switch)

1️⃣ Sur le PC 2 : Répéter les étapes 1.1 et 1.2
   ───────────────────────────────────────────
   - Installer SSH (Étape 1.1)
   - Créer l'utilisateur testuser (Étape 1.2)

2️⃣ Sur le PC 2 : Trouver son adresse IP
   ────────────────────────────────────
   Commande :
   ┌────────────────────────────────────────────────────────────────┐
   │ ipconfig                                                       │
   └────────────────────────────────────────────────────────────────┘

   Cherchez dans le résultat :
   ┌────────────────────────────────────────────────────────────────┐
   │ Carte Ethernet Ethernet:                                       │
   │    ...                                                         │
   │    Adresse IPv4. . . . . . . . . . . . . .: 192.168.1.105     │
   │                                              └──────────┘      │
   │                                              NOTEZ CETTE IP !  │
   └────────────────────────────────────────────────────────────────┘

   Ou si vous êtes en WiFi :
   ┌────────────────────────────────────────────────────────────────┐
   │ Carte réseau sans fil Wi-Fi:                                   │
   │    ...                                                         │
   │    Adresse IPv4. . . . . . . . . . . . . .: 192.168.1.105     │
   └────────────────────────────────────────────────────────────────┘

3️⃣ Sur le PC 1 : Tester la connexion vers le PC 2
   ──────────────────────────────────────────────
   
   🔹 Test de ping :
   Commande (remplacez 192.168.1.105 par l'IP du PC 2) :
   ┌────────────────────────────────────────────────────────────────┐
   │ ping 192.168.1.105                                            │
   └────────────────────────────────────────────────────────────────┘

   Résultat attendu si ça marche :
   ┌────────────────────────────────────────────────────────────────┐
   │ Réponse de 192.168.1.105 : octets=32 temps=1ms TTL=128       │
   │ Réponse de 192.168.1.105 : octets=32 temps<1ms TTL=128       │
   │ Réponse de 192.168.1.105 : octets=32 temps<1ms TTL=128       │
   │                                                                │
   │ Paquets : envoyés = 4, reçus = 4, perdus = 0                 │
   └────────────────────────────────────────────────────────────────┘

   ❌ Si le ping échoue, voir "RÉSOLUTION DES PROBLÈMES" plus bas

   🔹 Test SSH :
   Commande (remplacez par l'IP du PC 2) :
   ┌────────────────────────────────────────────────────────────────┐
   │ ssh testuser@192.168.1.105                                    │
   └────────────────────────────────────────────────────────────────┘

   ✅ Si ça marche, vous êtes connecté au PC 2 !

  RÉSOLUTION DES PROBLÈMES
═══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────────┐
│ PROBLÈME 1 : "Impossible de se connecter au serveur !" (SSH)               │
└─────────────────────────────────────────────────────────────────────────────┘

✅ SOLUTIONS :

1️⃣ Vérifier que le service SSH est actif
   ──────────────────────────────────────
   PowerShell :
   ┌────────────────────────────────────────────────────────────────┐
   │ Get-Service sshd                                               │
   └────────────────────────────────────────────────────────────────┘

   Si "Stopped", démarrez-le :
   ┌────────────────────────────────────────────────────────────────┐
   │ Start-Service sshd                                             │
   └────────────────────────────────────────────────────────────────┘

2️⃣ Tester SSH en ligne de commande
   ────────────────────────────────
   ┌────────────────────────────────────────────────────────────────┐
   │ ssh testuser@localhost                                         │
   └────────────────────────────────────────────────────────────────┘

   Si ça marche en ligne de commande mais pas dans l'app :
   - Vérifiez le username/password dans l'app
   - Vérifiez que le port est bien 22

3️⃣ Vérifier le pare-feu
   ────────────────────
   ┌────────────────────────────────────────────────────────────────┐
   │ Get-NetFirewallRule -Name sshd                                │
   └────────────────────────────────────────────────────────────────┘

   Si la règle n'existe pas, créez-la (voir Étape 1.1.5)

4️⃣ Redémarrer le service SSH
   ─────────────────────────
   ┌────────────────────────────────────────────────────────────────┐
   │ Restart-Service sshd                                           │
   └────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│ PROBLÈME 2 : Le ping vers le PC 2 échoue                                   │
└─────────────────────────────────────────────────────────────────────────────┘

✅ SOLUTIONS :

1️⃣ Vérifier que les 2 PCs sont sur le même réseau
   ──────────────────────────────────────────────
   - Même WiFi ou même switch/routeur
   - Même plage d'adresses (ex: 192.168.1.x)

2️⃣ Désactiver temporairement le pare-feu du PC 2
   ─────────────────────────────────────────────
   ⚠️ Pour tester uniquement ! Réactivez-le après !
   
   Windows :
   - Panneau de configuration
   - Système et sécurité
   - Pare-feu Windows Defender
   - Activer ou désactiver le Pare-feu Windows Defender
   - Cochez "Désactiver" (temporairement)

   Testez le ping. Si ça marche maintenant, c'est le pare-feu.

3️⃣ Créer une règle de pare-feu pour ICMP (ping)
   ────────────────────────────────────────────
   Sur le PC 2, PowerShell Admin :
   ┌────────────────────────────────────────────────────────────────┐
   │ New-NetFirewallRule -DisplayName "Allow ICMP"                 │
   │   -Direction Inbound -Protocol ICMPv4 -IcmpType 8             │
   │   -Action Allow                                                │
   └────────────────────────────────────────────────────────────────┘

4️⃣ Vérifier l'adresse IP
   ─────────────────────
   Sur le PC 2 :
   ┌────────────────────────────────────────────────────────────────┐
   │ ipconfig                                                       │
   └────────────────────────────────────────────────────────────────┘

   Assurez-vous d'utiliser la bonne adresse IPv4

└─────────────────────────────────────────────────────────────────────────────┘

   ────────────────────────────────────
   Le FileCollector cherche les fichiers dans des chemins spécifiques.
   
   Par défaut, il cherche dans :
   - C:\TestData\
   - C:\Users\[user]\Documents\
   - Le home directory de l'utilisateur SSH

   Solution : Créer des fichiers dans C:\TestData\Siemens_Files\

3️⃣ Examiner les logs d'erreur
   ──────────────────────────
   Si la collecte échoue, notez le message d'erreur exact
